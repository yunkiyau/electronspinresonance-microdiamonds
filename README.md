# Optical Detection of Electron Spin Resonance in NV⁻ Centres

This repository contains the code and documentation for running a compact ODMR (Optically Detected Magnetic Resonance) platform on nitrogen-vacancy (NV⁻) centres in microdiamonds. The platform uses laser excitation, microwaves, and synchronized photodetection to resolve zero-field and Zeeman-split spin transitions in diamond NV⁻ centres.

---

## Project Summary

Negatively charged NV⁻ centres in diamond exhibit spin-dependent fluorescence under optical excitation and microwave driving. In this project, I built a tabletop system to:

- Resolve zero-field ESR transitions (~2.87 GHz)
- Detect Zeeman splitting under external magnetic fields
- Automate measurement control and data acquisition using Python

The results demonstrate that even with modest, off-the-shelf optomechanical hardware, it is possible to implement and measure quantum control in a solid-state sensing system.

**Key hardware**:  
- SG4400L RF Signal Generator (DS Instruments)
- Thorlabs SPCM20A Single-Photon Detector (Thorlabs)
- Moku:Lab Oscilloscope (Liquid Instruments)
- Neodymium magnet (~2.6 mT)

---

## System Overview

The experimental setup includes:
- A 532 nm laser diode.
- Optomechanics for beam shaping and focusing.
- Dichroic mirrors and optical filters for fluorescence detection.
- Microwave delivery via PCB stripline (constructed by Dr. Cyril Laplane).
- Python-based serial control of RF source and data acquisition.

A detailed description of the optical and microwave layout is provided in the accompanying report.

---

## Software Overview

The experiment is operated via a Python control and acquisition script that interfaces directly with laboratory instrumentation. The software is responsible for:

- Configuring and sweeping the RF signal generator
- Toggling microwave excitation during acquisition
- Acquiring and averaging photon-count data
- Performing real-time plotting of ODMR spectra
- Saving experimental data for offline analysis

The emphasis of the software design is on reliable control of physical hardware and transparent interpretation of measurement data.

## Installation

This project requires **Python 3.9 or later**.
Install the required Python dependencies using:

```bash
pip install -r requirements.txt
```

Instrument drivers (e.g. VISA backend for PyVISA) must be installed separately according to the connected hardware and operating system.

## Usage
The main experiment automation script is:

```bash
python src/odmr_control.py
```

Experimental parameters such as frequency range, step size, integration time, and instrument addresses are configured at the top of the script.
